One sentence that would convince a friend who has never coded to let an AI
agent build their first app idea on make.fun. The pitch: your app idea is
already the hard part, so just describe it in plain words, let an agent
build it, and pay only if you love what it makes.

`main.py` (standard library only) writes that one sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — 148 characters, inside the 240-character
cap — and reads it back to prove the bytes round-tripped exactly.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
